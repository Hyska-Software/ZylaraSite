有些格式没法直接写成文本。为了生成 PDF、DOCX、XLSX、演示文稿或图片，智能体会写一小段脚本
并运行它，然后把生成的文件作为产物交回来。这就是 **代码执行** 功能，在你启用之前它一直是
关闭的。

## 如何启用

1. 打开 **设置 → 工具 → 代码执行**。
2. 打开 **允许代码执行**。
3. 设置 **执行超时**（10 到 600 秒；默认 120）。
4. 查看 **代码环境** 区块：它列出 Python 和 Node 的版本，以及路径是你指定的还是在 `PATH`
   中探测到的。安装了解释器之后，**重新检查** 会重跑一次探测。

开关关闭时，这个工具根本不会提供给模型。开启后，应用会提示代码将在这台机器上以你的权限和
网络环境运行——参见 [安全](#安全)。

## 解释器

- **Python**：指定的路径，或 `PATH` 中的 `python`、`python3` 或 `py`。
- **Node**：指定的路径，或 `PATH` 中的 `node`。

不会自动下载任何东西。如果两者都缺失，智能体仍然可以写文本格式，只是无法构建二进制格式。

可选包能改善输出：`python-docx`、`openpyxl`、`python-pptx`、`reportlab` 和 `Pillow`。设置
界面会列出哪些已经可用，并提供 **复制安装命令**；是否安装由你决定。

## 限制

| 限制项 | 数值 |
| --- | --- |
| 代码大小 | 100 KB |
| 输入文件 | 10 个文件，每个 1 MB |
| 输出文件 | 20 个文件，每个 25 MB，合计 64 MB |
| 工作区大小 | 128 MB |
| stdout / stderr | 各 64 KB |
| 超时 | 默认 120 秒，最小 10 秒，最大 600 秒；单次调用可请求 5 秒到 10 分钟 |
| 取消 | 整个进程树都会被终止 |

超出限制的输出会被截断并附上说明；即使退出码非零，已生成的文件仍会保留。

## 工作区生命周期

每次运行都会在 `<app-data>/code-runs/<id>/` 下获得一个全新目录，里面只有你允许的输入文件。
运行结束时：

1. 收集新生成的文件并登记为产物。
2. 删除工作区。
3. 工具返回摘要，包含退出码、控制台输出和产物 id。

这个工具不会往你的项目或主目录里写任何东西。

## 安全

代码执行 **不是操作系统级沙箱**。脚本以你的用户身份运行，拥有你的权限和网络。它的防护包括：

- 每次安装都需要显式开启；
- 一次性工作区、超时、输出上限和进程树取消；
- 清理过的环境：匹配 `*API_KEY*`、`*TOKEN*`、`*SECRET*`、`LD_*`、`DYLD_*` 的变量以及应用
  自身的路径都会被移除，因此脚本拿不到应用凭据；
- 智能体会被要求只运行生成目标文件所需的代码。

如果需要更强的命令隔离，请使用 **设置 → 工具** 中的 Docker **命令沙箱**，它作用于 shell
命令和后台作业——不作用于这个工具。参见
[权限与批准](/docs/permissions-and-approvals#docker-命令沙箱)。

## 与技能的关系

智能体不必自己发明脚本。内置技能（`pdf`、`office-docx`、`office-xlsx`、`office-pptx`、
`imagens`）包含说明和小的标准库辅助脚本，可以产出有效的文件。典型流程是：读取技能、写出
规格、运行辅助脚本、登记产物。参见 [技能](/docs/skills)。

## 失败时

| 消息 | 原因 |
| --- | --- |
| "代码执行已停用" | **设置 → 工具** 中的开关是关闭的 |
| "未找到 Python" / "未找到 Node" | `PATH` 中没有解释器，也没有配置路径 |
| "已超时" | 脚本超过了超时时间；简化脚本或提高上限 |
| "输出超出限制" | 控制台输出太多；请把结果写入文件 |
| 退出码非零 | 脚本执行失败；控制台输出在工具结果里 |

更多：[疑难解答](/docs/troubleshooting)。
