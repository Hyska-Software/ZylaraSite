用 `Ctrl/⌘ ,`、侧边栏的齿轮，或命令面板中的 **打开设置** 打开设置。标签页顺序始终是：通用、
主题、设计、终端、提供商、默认模型、指令、工具、插件、智能体、数据、关于。插件可以在末尾追加
自己的标签页。

## 通用

| 控件 | 取值 |
| --- | --- |
| **主题** | **浅色**、**深色**、**跟随系统** |
| **语言** | 英语（默认）、Português (Brasil)、Español |
| **字号** | 90%–115%，每档 5% |
| **布局** | 显示或隐藏 **聊天**、**代码**、**智能体** |
| **发送方式** | `Enter` 或 `Ctrl/⌘ Enter`；`Shift+Enter` 始终是换行 |
| **减少动效** | 关闭过渡与动画 |
| **显示 token 用量** | 每条回答下方显示 token 数与耗时 |
| **默认折叠思考过程** | 思考区块初始为关闭状态 |
| **自动压缩阈值** | 50%–90%，默认 85% |
| **关闭窗口后驻留系统托盘** | 关闭窗口后轮次与排期仍继续运行 |

## 主题

外观模式、已安装主题列表（内置 **Zylara** 加上附带的 **aurora**、**ember**、**grove**、
**nebula**、**nocturne**）、**安装主题…**、**重新加载主题**、**打开主题文件夹**，以及每个
主题的 **使用** / **使用中** / **移除**。参见
[自定义](/docs/customization#主题)。

## 设计

由插件贡献的界面：布局标签页（**聊天**、**代码**、**智能体**）、**预设**、**组件变体**、
**停用插件界面** / **启用插件界面**、**重置此布局**、**重置全部插件界面**，以及 **冲突** 与
**生效中的修改**。

| 控件 | 默认值 |
| --- | --- |
| 字体族 | JetBrains Mono Variable |
| 字号 | 跟随主题 |

## 提供商

推荐提供商（OpenCode Go、OpenCode Zen、OpenAI、Anthropic、Gemini）、用于其余 21 家的
**查看更多提供商**、每个提供商的 **连接** / **管理**、API 密钥输入框、**测试连接**、
**刷新模型**、**控制台**（提供商面板）、**打开数据文件夹**。

**OpenAI** 还会显示 **使用 ChatGPT 继续**、**复制链接**、**退出登录**、**使用 API 密钥作为
备选**，以及登录后的套餐用量。

**添加提供商** 可注册自定义的 OpenAI 兼容端点；`http://` 仅在 localhost 下被接受。

每个提供商的 **可靠性** 设置：

| 控件 | 默认值 |
| --- | --- |
| **响应头超时（秒）** | 120 |
| **首 token 超时（秒）** | 180 |
| **流空闲超时（秒）** | 120 |
| **流总超时（秒）** | 1800（30 分钟） |
| **每步重试次数** | 提供商默认值 |
| **基础退避（毫秒）** / **最大退避（毫秒）** | 提供商默认值 |
| **重试预算（毫秒）** | 提供商默认值 |
| **最大 Retry-After（毫秒）** | 提供商默认值 |

`0` 会关闭某个超时或重试预算。参见
[模型与提供商](/docs/models-and-providers#超时与重试)。

## 默认模型

新对话使用的提供商、模型和默认思考模式。模型始终可以在输入框里切换；这个标签页只设置起点。

## 指令

应用于你所有对话的自由文本系统指令，带字符计数和自动保存。它作为系统提示词的一部分发送，
因此修改它会让已有对话的提示缓存失效。

## 工具

### 智能体工具

| 开关 | 效果 |
| --- | --- |
| **网页搜索** | 向模型提供搜索工具 |
| **创建文件** | 提供产物创建能力 |
| **把附件发送给模型** | 在请求中包含附件内容 |
| **自动生成标题** | 用第一条消息为对话命名 |

### 提示缓存

| 控件 | 取值 |
| --- | --- |
| **显示指示器** | 在聊天中显示缓存胶囊，在代码中显示上下文计量器 |
| **缓存 TTL（Anthropic）** | 1 小时（默认）或 5 分钟 |
| **缓存保留（OpenAI）** | 自动、内存中、24 小时 |

### 代码执行

**允许代码执行**（默认关闭）和 **执行超时**（10–600 秒，默认 120）。参见
[代码执行](/docs/code-execution)。

### 命令沙箱

**环境**（**这台电脑** 或 **Docker**）、**Docker 镜像**（默认 `node:22-bookworm`）、
**容器内网络**、**内存（MB）**、**CPU**、**PID**、**只读 rootfs**、**校验镜像**、**下载镜像**。
参见 [权限与批准](/docs/permissions-and-approvals#docker-命令沙箱)。

### 代码会话

| 控件 | 取值 |
| --- | --- |
| **默认权限模式** | **只读**、**审阅**、**编辑**、**自主** |
| **打开文件差异** | **在聊天标签页中（默认）** 或 **在侧面板中** |

### 代码环境

Python 与 Node 探测（配置的路径或 `PATH`）、版本、**重新检查**、可选包列表（`python-docx`、
`openpyxl`、`python-pptx`、`reportlab`、`Pillow`）以及 **复制安装命令**。

### 技能

**侧边栏技能面板**、按来源统计的数量、**管理技能**、**打开技能文件夹**。参见
[技能](/docs/skills)。

## 插件

**启用插件**、**自动更新**、**允许受信任插件**、**开发者模式**、**安全模式**、**仓库 URL**、
**停用全部插件**。参见 [插件](/docs/plugins)。

## 智能体

| 区块 | 控件 |
| --- | --- |
| **执行与队列** | 全局并发轮次、每个智能体的轮次（默认 1）、每个线程排队消息数 |
| **预算** | 每个智能体的每日上限，单位为美元 |
| **通知** | 已启用、**勿扰**、**批准**、**提问**、**完成**、**任务** |
| **受控浏览器** | 允许的主机、阻止的主机、私有主机、例行任务中的浏览器 |
| **桌面应用** | 电脑操作允许与阻止的应用 |
| **私有桌面** | 镜像、容器状态、每轮操作数（20）、每小时操作数（120）、清理、诊断 |

参见 [智能体](/docs/agents) 与 [电脑操作](/docs/computer-use)。

## 数据

| 区块 | 内容 |
