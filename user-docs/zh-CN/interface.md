Zylara 只有一个窗口：标题栏、侧边栏、中间列（对话记录加输入框）和一个可选的右侧面板。三种布局共用这个框架，只改变侧边栏和可用的工具。

## 标题栏

| 元素 | 作用 |
| --- | --- |
| 品牌标识 | 返回布局首页 |
| **切换侧边栏** | 显示或隐藏侧边栏（`Ctrl/⌘ B`） |
| **聊天 · 代码 · 智能体** 胶囊 | 切换布局。右键点击它可以隐藏你不使用的布局。只启用一种布局时隐藏。 |
| **ChatGPT 套餐** 标签 | 使用 ChatGPT 登录时出现；打开套餐用量 |
| 更新标签 | 存在更新的稳定版本时出现 |
| 窗口控件 | 最小化、最大化、关闭 |

## 侧边栏（聊天布局）

从上到下：

1. **新建对话** — 开始一个空对话（`Ctrl/⌘ N`）。
2. **资料库** — 每个对话中的每个文件，以及你上传的文件。
3. **插件** — 已安装、可发现和可更新的插件。
4. **技能** — 启用、停用和查看技能（在 **设置 → 工具** 中关闭 **侧边栏中的技能面板** 时隐藏）。
5. **搜索对话** — 打开命令面板（`Ctrl/⌘ K`）。
6. 对话历史记录，按 **已置顶**、**今天**、**昨天**、**最近 7 天**、**最近 30 天** 和 **更早** 分组。行可以用 `Alt+↑` / `Alt+↓` 重新排序。
7. 页脚的 **设置**，附带应用版本。

每个对话行都有一个 `⋯` 菜单：**置顶/取消置顶**、**重命名**、**导出**（Markdown）、**在代码中使用** / **从代码中移除**、**删除**。

## 输入框

中间列底部的浮动输入区域。

| 控件 | 用途 |
| --- | --- |
| **+** | 附加文件（文档、图片或所有文件） |
| 地球开关 | 本条消息的 **网页搜索** |
| 工具开关 | **创建文件**（产物） |
| 模型胶囊 | 打开 **选择模型** |
| ✦ | 思考模式（强度或预算） |
| 发送 / ⚡ / ↑ | 发送、**立即发送**（中断）、流式输出时 **排队消息** |
| ■ | **停止回答** |
| 权限标签 | 仅代码和智能体布局 — 参见[权限与批准](/docs/permissions-and-approvals) |
| 计划标签 | 仅代码和智能体布局 — 计划和任务进度 |

输入框下方：*“Zylara 可能会出错。请核对重要信息。”*

输入 `/` 打开斜杠命令（插件、`/creator`，以及代码命令 `/plan`、`/compact`、`/commit`、`/test`、`/review` 等），输入 `@` 引用文件 — `@` 需要工作区，因此它出现在代码布局和带有文件夹的智能体会话中。

## 对话记录

每个回答按顺序可能包含：

- 一个 **思考区块**（如果你启用了 **默认折叠思考**，则默认折叠），列出推理和每次工具调用及其状态和可展开的输出；
- Markdown 回答，包含表格、数学公式、图表和代码；
- 智能体搜索网页时的 **引用标签**；
- 生成文件的 **产物卡片**；
- 一个页脚，包含 **复制回答**、**重新生成回答**、**有帮助** / **没有帮助**、模型名称，以及启用时显示的 token 和耗时。

你自己的消息带有 **复制消息** 和 **编辑消息**（编辑时提供 **保存并重新发送**）。流式输出期间，如果你向上滚动，会出现 **跳到对话末尾** 按钮。

## 右侧面板

同一个停靠区承载两个面板：

- **产物** — 文件列表，带按格式预览、**另存为…**、**在默认应用中打开**、**删除** 以及上一个/下一个导航。参见[产物](/docs/artifacts)。
- **来源** — 智能体读取过的每个页面，带标题、域名和链接。它可以浮在聊天之上，也可以停靠在聊天旁边，并且可以调整大小。

在代码和智能体布局中，这个停靠区还会显示 文件/更改/终端 面板 — 参见[工作台](/docs/code-workbench)。

## 命令面板

`Ctrl/⌘ K` 可在任何位置打开它。以 `>` 开头搜索命令，以 `#` 开头搜索对话；不带前缀时两者都搜索。

命令按 **对话**、**导航**、**工具**、**插件**、**外观**、**设置** 和 **系统** 分组，包括：新建对话、置顶对话、导出、复制上一个回答、停止回答、重新生成、切换布局、聚焦输入框、切换侧边栏、打开产物或来源、打开资料库、管理技能、切换模型、切换网页搜索、创建文件或代码执行、切换主题、打开设置、打开数据文件夹、重新加载模型目录，以及从文件安装插件。

`↑`/`↓` 导航，`Enter` 执行，`Ctrl/⌘ Enter` 执行次要操作（置顶/取消置顶），`Esc` 清空搜索，然后再关闭。

## 空状态

新对话显示 **“我能帮你做什么？”**，以及四个建议卡片 — **分析文档**、**搜索网页**、**创建文件**、**解释代码** — 还有命令、侧边栏和发送的快捷键提示。
