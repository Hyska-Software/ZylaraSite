---
title: 网页搜索与来源
description: 让智能体搜索网页、阅读页面，并为它用到的每个来源标注引用。
---

启用网页搜索后，智能体可以上网查资料，而不必只依赖训练数据；它用到的每个页面都会列在来源
中。

## 如何启用

- 输入框里的地球按钮为当前对话启用 **网页搜索**。
- **设置 → 工具 → 智能体工具 → 网页搜索** 控制默认值。
- 命令面板中有 **启用网页搜索** / **停用网页搜索**。

开关关闭时，这个工具根本不会提供给模型，因此不会误触发搜索。

## 一轮对话中会发生什么

1. 模型判断需要查询，调用 `web_search`，传入查询词和可选的结果数量（1–8，默认 8）。
2. 应用向搜索引擎查询，返回标题、URL 和摘要。
3. 如果某个结果看起来相关，模型调用 `fetch_url` 读取页面：页面被下载、提取为可读文本，
   再截断以适配上下文。
4. 回答中标注它用到的 URL。

搜索请求发送到 Bing（RSS 接口，备用 Bing HTML 与 DuckDuckGo）——不会发送给模型提供商。
这意味着即使模型本身运行在其他地方，查询词仍然会离开你的电脑前往搜索引擎。不想发给搜索
引擎的查询，请关闭网页搜索。

## 引用

- 回答下方会出现引用标签，带有数量（"N 个来源"）和打开侧面板完整列表的操作。
- **来源** 面板列出每个页面的标题、域名和链接；链接在你的默认浏览器中打开。
- 只有智能体真正读过的页面才会被引用，而不是每条搜索结果。

## 适用场景

- 近期新闻、版本发布、价格、文档版本，以及模型知识截止之后的任何内容。
- 用一手来源核对某个说法。
- 阅读你提供的某个 URL。

## 限制与行为

- 每次调用最多返回八条结果；摘要很短，所以模型必须抓取页面才能读到全文。
- 有些页面会阻止自动请求，或只返回依赖 JavaScript 的内容；智能体会报告失败，而不是编造
  内容。
- 页面内容被视为 **不可信数据**：智能体会被要求不执行页面中出现的指令，而是把它们当作待
  总结的内容。
- 搜索质量取决于查询语言；工具会要求模型用你提问的语言搜索。

## 隐私

搜索查询和抓取的 URL 会离开你的电脑。如果你需要完全本地的一轮对话，请在输入框和
**设置 → 工具** 中关闭网页搜索。其他会离开本机的内容列在
[数据与隐私](/docs/data-and-privacy#什么会离开本机) 中。
