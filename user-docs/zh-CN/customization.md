外观设置分为 **通用**（行为与基础项）、**主题**（已安装的主题包）、**设计**（由插件贡献的
界面）和 **终端**。

## 外观

| 设置项 | 位置 | 选项 |
| --- | --- | --- |
| 主题 | **设置 → 通用 → 主题** | **浅色**、**深色**、**跟随系统** |
| 字号 | **设置 → 通用 → 字号** | 90% 到 115%，每档 5% |
| 语言 | **设置 → 通用 → 语言** | 英语（默认）、Português (Brasil)、Español |
| 减少动效 | **设置 → 通用 → 减少动效** | 关闭过渡与动画 |
| 布局 | **设置 → 通用 → 布局** | 显示或隐藏聊天、代码和智能体 |

标题栏里的布局胶囊也有右键菜单，提供同样的显示开关。只启用一种布局时，胶囊会被隐藏。

## 行为偏好

| 设置项 | 效果 |
| --- | --- |
| **发送方式** | `Enter` 或 `Ctrl/⌘ Enter`；`Shift+Enter` 始终插入换行 |
| **显示 token 用量** | 每条回答下方显示 token 数与耗时 |
| **默认折叠思考过程** | 思考区块初始为关闭状态 |
| **自动压缩阈值** | 上下文窗口的 50% 到 90%，默认 85% |
| **关闭窗口后驻留系统托盘** | 关闭窗口后应用及其中的轮次继续运行 |

## 主题

**设置 → 主题** 列出已安装的主题和内置的 **Zylara** 配色。内置的额外主题包括 **aurora**、
**ember**、**grove**、**nebula** 和 **nocturne**。

| 操作 | 结果 |
| --- | --- |
| **使用** | 立即应用该主题；当前主题标记为 **使用中** |
| **安装主题…** | 打开 `.zip` 主题包 |
| **重新加载主题** | 手动复制文件后重新读取主题目录 |
| **打开主题文件夹** | 显示 `<app-data>/themes/` |
| **移除** | 删除已安装的副本；磁盘上的原始包不受影响 |

### 主题包

主题是一个 ZIP（最大 24 MB，最多 256 个文件），根目录下或唯一的顶层文件夹里有一个
`theme.json`：

```
my-theme/
  theme.json
  fonts/        (optional)
  images/       (optional)
```

只会解出清单引用的文件（`fonts`、`wallpaper`），文件名必须使用 `/`，不能包含 `..` 或绝对
路径。重新安装同一个 id 会原子地替换该文件夹。主题通过设计 token 定义颜色、圆角、排版和可选
壁纸——应用绝不会执行主题里的代码。

## 设计（插件界面）

插件可以贡献侧边栏条目、页面、面板、插槽和组件变体。**设计** 标签页显示每种布局当前使用的
内容：

| 控件 | 结果 |
| --- | --- |
| 布局标签页（**聊天**、**代码**、**智能体**） | 选择要检查的布局 |
| **预设** / **组件变体** | 选择当前预设和各组件的变体 |
| **停用插件界面** / **启用插件界面** | 在所有布局中隐藏全部插件贡献的界面，而无需卸载任何东西 |
| **重置此布局** / **重置全部插件界面** | 恢复宿主默认值 |
| **冲突** 与 **生效中的修改** | 显示谁覆盖了谁 |

当某个插件的界面出问题时，这里也是恢复路径：先停用插件界面，再到
[插件](/docs/plugins) 中移除该插件。

## 终端

**设置 → 终端** 设置集成终端以及跟随终端字体的代码块所使用的字体族（默认 JetBrains Mono
Variable）和字号。

## 哪些不能自定义

- 不支持任意 CSS 注入：颜色和间距来自当前主题的 token。
- 输入框布局、对话记录顺序和面板位置按布局固定。
- 插件界面可以被停用，但不能超出插件声明的预设范围重新排列。
