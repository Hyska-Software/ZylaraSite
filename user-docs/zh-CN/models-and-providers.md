Zylara 不内置模型访问能力。你连接一个提供商，请求会带着你的凭据从你的机器直接发送到该提供商的 API。

## 支持的提供商

内置目录包含 **26 个提供商和 464 个模型**。**设置 → 提供商** 中重点展示其中五个：

| 提供商 | 认证 | 说明 |
| --- | --- | --- |
| **OpenCode Go** | OpenCode Console 密钥 | 以订阅方式访问 Go 目录（45 个模型） |
| **OpenCode Zen** | OpenCode Console 密钥 | 以额度方式访问 Zen 目录（92 个模型） |
| **OpenAI** | API 密钥 `sk-…` **或** **使用 ChatGPT 继续** | ChatGPT 登录会为符合条件的模型使用你的套餐 |
| **Anthropic** | API 密钥 `sk-ant-…` | 官方 API，按使用量付费；没有订阅式登录 |
| **Gemini** | API 密钥 `AIza…` | 也接受 `GOOGLE_API_KEY` |

**查看更多提供商** 列出另外 21 个基于密钥的服务：DeepSeek、xAI（Grok）、Mistral、Moonshot（Kimi）、Z.AI（GLM）、MiniMax、Inception（Mercury）、StepFun、OpenRouter、Vercel AI Gateway、Groq、Together AI、Fireworks AI、Cerebras、NVIDIA NIM、DeepInfra、SiliconFlow、SambaNova、Scaleway、Novita AI 和 Venice AI。

## 连接提供商

1. 打开 **设置 → 提供商**。
2. 在该提供商上按 **连接** 并粘贴密钥。
3. 按 **继续**。保存密钥也会获取该账户的模型列表。

提供商行会显示凭据的来源：

| 徽章 | 含义 |
| --- | --- |
| **已配置** | 密钥已保存在 `secrets.json` 中 |
| **环境变量** | 从环境中检测到（`OPENAI_API_KEY`、`ANTHROPIC_API_KEY`、`GEMINI_API_KEY`/`GOOGLE_API_KEY`、`OPENCODE_API_KEY`、…） |
| **OpenCode CLI** | 复用已有的 OpenCode CLI 登录 |
| **ChatGPT 账户** | 使用 ChatGPT 而非密钥登录 |
| **缺失** | 没有凭据；无法使用该提供商的模型 |

解析顺序是设置 → 环境 → OpenCode CLI，密钥永远不会发送到界面。使用 **测试连接** 可以验证密钥而不做任何改动。

### 使用 ChatGPT 继续

OpenAI 支持官方的 *使用 ChatGPT 登录* 流程：

1. **设置 → 提供商 → OpenAI → 使用 ChatGPT 继续**。
2. 系统浏览器打开 OpenAI 的授权页面；应用在回环端口上接收回调。
3. 返回后，提供商徽章显示 **ChatGPT 账户**，标题栏中会出现 **ChatGPT 套餐** 标签。

符合条件的请求会使用你的套餐；该限额在使用同一账户的多个应用间共享。应用绝不会编造百分比或重置时间 — **管理用量** 会打开提供商自己的页面。你可以保留一个 API 密钥作为回退（**将 API 密钥用作回退**），**退出登录** 会吊销该会话。

### 自定义 OpenAI 兼容提供商

**添加提供商** 可以注册任何使用 OpenAI 聊天协议的端点 — 对 Ollama、LM Studio 或 vLLM 很有用。`http://` 只在 localhost 下被接受；远程端点必须使用 HTTPS。自定义提供商以 `custom__` 开头的 id 存储。

## 模型目录

目录随应用一起发布，因此模型选择器可以离线工作。它根据各提供商的官方文档和 models.dev 生成，每条记录包含上下文大小、最大输出、价格、协议、视觉和思考支持。

- 保存密钥会合并该账户报告的模型。
- **刷新模型**（在 **设置 → 提供商** 中，或命令面板中的 **重新加载模型目录**）会重新读取每个已配置的提供商。
- 目录中没有描述的、仅账户可见的模型会标记为 **估算**。

## 选择模型

点击输入框中的模型胶囊打开 **选择模型**：

- **搜索模型…** 会匹配名称、系列、标识符和能力。
- 筛选：**收藏**、**视觉**、**思考**、**免费**。
- 提供商下拉菜单，默认为 **所有提供商**。
- 每个模型的徽章：**免费**、**视觉**、**思考**、**开放**、**预览**、**不可用**，以及套餐内模型的 **ChatGPT 套餐**。
- 详情行：**上下文**、**最大输出**、**费用（1M tok.）**、**输入**、**协议**、**知识截止**、**发布**。
- **使用此模型** 确认；**使用中** 标记当前模型。

模型在一个轮次内是固定的（否则会提示 *“等待当前回答完成”*），并且属于对话或代码会话，而不属于应用。标记收藏可以把短列表保留在顶部。

## 思考模式

模型胶囊旁边的 ✦ 按钮设置模型应思考多少：

| 控件 | 选项 |
| --- | --- |
| **关闭** | 直接回答，不进行扩展思考 |
| 强度 | **最低**、**低**、**中**、**高**、**很高**、**最高** |
| 预算 | **快速（~4k）**、**平衡（~8k）**、**深度（~16k）**、**最高（~32k）**，或在模型限制之间滑动的滑块 |
| 开启 | 仅提供开关的模型 |

并非每个模型都提供该控件；不提供时，应用会显示 *“此模型没有开放思考控制”*，而仅支持思考的模型需要选择一个强度档位。对于接受重放思考的模型系列，思考会被重放到下一次请求；选择 **关闭** 会禁用该重放。

## 用量与费用

- **设置 → 通用 → 显示 token 用量** 会在每个回答下添加 token 和耗时。
- 模型详情显示目录所报告的每百万 token 价格。
- **提示缓存**：启用 **设置 → 工具 → 提示缓存 → 显示指示器** 后，聊天输入框和代码上下文计量器中会出现缓存标签，显示命中率，以及缓存失效时的原因。参见[目标与任务](/docs/goals-and-tasks#上下文与缓存)。
- 智能体在 **设置 → 智能体 → 预算** 中有每个智能体的每日预算。

## 超时与重试

针对每个提供商，**设置 → 提供商 → 可靠性** 控制 **响应头超时（秒）**（120）、**首个 token 超时（秒）**（180）、**流空闲超时（秒）**（120）和 **总流超时（秒）**（1800）— `0` 表示不限制 — 以及 **每步重试次数**、退避和 `Retry-After` 上限。默认值适用于大多数网络；如果思考模型启动较慢，可以提高首个 token 超时。

## 常见情况

| 情况 | 含义 |
| --- | --- |
| “没有 *提供商* 的 API 密钥” | 所选模型属于你尚未连接的提供商 |
| 模型显示 **不可用** | 提供商已不再提供该模型，或你的账户没有访问权限 |
| 回答提前结束 | 提供商限制、达到上下文窗口，或网络中断；部分文本会被保留 |
| **估算** 徽章 | 该模型来自账户列表，而不是内置目录 |

更多内容见[疑难解答](/docs/troubleshooting)。
