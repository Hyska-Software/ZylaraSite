---
title: 资料库
description: 所有对话的全部文件，加上你自己上传的文件，集中在一个可搜索的页面里。
---

资料库汇集了智能体在任何对话中创建的每一个产物，以及你自己上传到那里的文件。当你想找到上个
月生成的一份报告，却记不清是哪个对话做的，这里就是该来的地方。

可以从侧边栏（**资料库**）打开，或在命令面板中用 **打开资料库**。这个页面会取代对话栏；
**返回对话** 或按 `Esc` 即可回去。

## 布局

| 控件 | 选项 |
| --- | --- |
| 搜索 | **搜索资料库**——匹配文件名、文件类型以及来源对话 |
| 排序 | **最近**、**最早**、**名称（A–Z）**、**大小** |
| 视图 | **网格** 或 **列表** |
| 筛选 | **全部**、**收藏**、**图片**、**文档**、**代码**、**媒体**、**其他**，各自带有数量 |
| 上传 | **上传文件**，或把文件拖到页面上（"拖放以上传到资料库"） |

空状态说得很明白：什么都没有时显示 **资料库还是空的**；筛选条件把内容全部隐藏时显示
**未找到产物**，并给出 **清除筛选** 按钮。

## 处理文件

每张卡片（或列表行）提供：

| 操作 | 结果 |
| --- | --- |
| **打开** | 打开预览对话框，带 **上一个** / **下一个** 导航和当前在列表中的位置 |
| **重命名** | 修改显示的文件名 |
| **加入收藏** / **取消收藏** | 为 **收藏** 筛选打标记 |
| **另存为…** | 把副本写到磁盘任意位置 |
| **删除** | 确认后移除该文件 |

预览对话框使用的渲染器与产物面板相同：PDF 页面、DOCX 的 HTML、XLSX 工作表、PPTX 幻灯片、
可缩放的图片、音频/视频播放器、Markdown、JSON 树、CSV 表格、带高亮的代码，以及未知二进制
文件的十六进制转储——参见
[产物](/docs/artifacts#按格式预览)。

## 你上传的文件

上传会把文件放进资料库，并让它作为上下文在后续轮次中可供智能体使用。想在手边保留一份参考
文档，又不想每条消息都附上它，这就是办法。

## 智能体如何使用资料库

智能体用 `list_artifacts` 搜索你的产物——匹配名称、对话标题和提取出的文本，忽略重音符号
——再用 `read_artifact` 读取任一结果。结果会显示每个文件来自哪个对话。读取文件会把内容带
入当前上下文，对 PDF、DOCX、XLSX 和 PPTX 做文本提取，对图片给出元数据和结构，对 ZIP 给出
列表，对长文本分页。

有两条与隐私有关的限制：资料库只暴露 **产物和元数据**，绝不包含其他对话的消息；内容以不可
信数据的形式注入——智能体会被要求不执行文件内部出现的指令。

## 存储

资料库文件位于应用数据目录下的 `artifacts/`。删除一个对话会移除在其中创建的产物；从资料库
删除一个文件会在所有位置移除它。上传的文件会一直保留，直到你删除它或清空应用数据。
