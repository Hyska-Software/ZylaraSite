先从应用显示的那条消息看起。大多数失败都会点名涉及的提供商、工具或文件，修复往往只差一个
设置。

## 提供商与凭据

| 现象 | 原因 | 修复 |
| --- | --- | --- |
| 输入框上方提示需要提供商 | 没有配置凭据 | 打开 **打开提供商** 并添加密钥，或用 ChatGPT 登录 |
| "没有 *提供商* 的 API 密钥" | 所选模型属于未连接的提供商 | 在 **设置 → 提供商** 中连接它，或改选一个你已有的提供商的模型 |
| 401 / 未授权 | 密钥错误、过期或被吊销 | 重新粘贴密钥，然后 **测试连接** |
| 某个模型返回 403 | 你的账号无权使用该模型 | 换一个模型，或升级提供商的套餐 |
| "ChatGPT 会话已过期" | OAuth 会话已结束 | 在 **设置 → 提供商 → OpenAI** 中 **重新连接** |

环境变量和已有的 OpenCode CLI 登录会被自动使用；提供商旁边的标记会告诉你当前生效的来源。

## 模型与回答

| 现象 | 原因 | 修复 |
| --- | --- | --- |
| 模型显示为 **不可用** | 提供商已下架，或你的账号无法使用 | 换一个模型 |
| 模型胶囊被禁用 | 正有一轮在运行 | 停止回答或等待 |
| 回答说到一半就停 | 提供商限额、上下文窗口或网络中断 | 重试，或新建一个对话 |
| 思考区块为空 | 该模型不流式输出思考过程 | 属正常；查看模型详情 |
| 回答忽略了附件 | 模型不支持视觉，或附件被禁用 | 使用 **视觉** 筛选并启用 **把附件发送给模型** |
| 费用看起来不对 | 价格来自目录，而不是发票 | 以提供商控制台为准 |

## 流式输出与轮次

| 现象 | 修复 |
| --- | --- |
| 轮次始终不开始 | 检查提供商标记；运行 **测试连接** |
| 首个 token 之前长时间静默 | 在 **设置 → 提供商 → 可靠性** 中调高 **首 token 超时** |
| 网络切换后卡住 | 停止该轮再重新发送；已生成的部分文本会保留 |
| "上下文已压缩"反复出现 | 调高 **自动压缩阈值**，或新建一个对话 |
| 后台会话结束但没有回答 | 打开该会话；通知设置位于 **设置 → 智能体 → 通知** |

## 文件、产物与资料库

| 现象 | 修复 |
| --- | --- |
| 没有产物卡片 | 在输入框中启用 **创建文件**；确认模型支持工具调用 |
| PDF/DOCX/XLSX 没有生成 | 启用 **代码执行** 并安装 Python 或 Node |
| 预览提示不可用 | 用 **另存为…** 保存后，在系统应用中打开 |
| Office 预览看起来很简陋 | 属预期：预览是结构性的，不含颜色和合并单元格 |
| 资料库什么都不显示 | 清除筛选；确认该对话没有被删除 |
| 扫描版 PDF 提取不到文本 | 没有 OCR；先把文件转换为文本 |

## 代码执行

| 现象 | 修复 |
| --- | --- |
| "代码执行已停用" | **设置 → 工具 → 代码执行 → 允许代码执行** |
| "未找到 Python" / "未找到 Node" | 安装解释器或设置路径，然后 **重新检查** |
| "已超时" | 简化脚本，或调高 **执行超时** |
| "输出超出限制" | 把结果写入文件，而不是打印出来 |
| 脚本以非零码退出 | 在工具结果中查看控制台输出；出错前已生成的产物会保留 |

## Docker、沙箱与电脑操作

| 现象 | 修复 |
| --- | --- |
| 未找到 Docker | 安装 Docker Desktop/Engine，然后按 **启动 Docker** |
| 命令沙箱启动失败 | 先 **校验镜像**，再 **下载镜像**；检查镜像名称 |
| 容器一直运行 | 在 **设置 → 工具** 或 **设置 → 智能体** 中 **清理容器** |
| 屏幕标签页是黑的 | 在私有桌面设置中运行 **诊断**；重启容器 |
| 电脑操作被拒绝 | 批准卡片，或为智能体授予该能力 |
| 接管时键盘卡住 | 按 `Ctrl+Alt+Shift+Q` |

## 插件

| 现象 | 修复 |
| --- | --- |
| 安装插件后应用无法启动 | 以 **安全模式** 或加 `--disable-plugins` 启动，然后移除该插件 |
| 插件界面消失 | **设置 → 设计 → 启用插件界面** |
| 安装被拒绝 | 检查签名、哈希和申请的权限；必须使用 HTTPS |
| 插件已安装但未启用 | 由智能体安装的插件默认停用；请自行启用 |
| 更新失败 | 回滚到上一个版本，然后重试 |

## 更新

| 现象 | 修复 |
| --- | --- |
| 没有更新通知 | **设置 → 关于 → 立即检查**；只支持稳定版 |
| 某个版本被跳过 | 更新的版本会覆盖 **跳过此版本**；请再次检查 |
| 下载失败 | 检查网络和可用空间；未完成的文件会被丢弃 |
| 没有"安装并重启" | 只有受管安装（Linux x64/macOS arm64 脚本）支持；否则请打开已下载的包 |
| 哈希不匹配 | 不要安装；从发布页面重新下载 |

## 性能

| 现象 | 修复 |
| --- | --- |
| 对话很长时应用变慢 | 新建一个对话；更早触发自动压缩 |
| 缓存命中率偏低 | 保持系统提示词和工具集合稳定；在 **缓存诊断** 中查看失效原因 |
| 产物很多后内存占用高 | 关闭预览；大型 PDF 和视频会被面板持有 |
| 某轮对话时风扇噪音大 | 推理模型使用的是提供商的 CPU/GPU，不是你的；本地负载来自预览 |

## 常见问题

**Zylara 需要账号吗？** 不需要。你连接一个提供商即可；没有 Zylara 登录。

**可以离线使用吗？** 应用能打开，历史记录也在本地，但回答需要提供商。网页搜索是唯一会与搜索
引擎通信的功能。

**我的 API 密钥在哪里？** 在数据文件夹的 `secrets.json` 中，只有后端会读取。参见
[数据与隐私](/docs/data-and-privacy#凭据)。

**卸载会丢失聊天吗？** 不会，除非你选择 **同时移除我的数据** 或 `--purge`。

**智能体能不经过我就提交吗？** 不能。它可以在权限模式内编辑文件并运行命令，但暂存、提交和
推送都需要你手动完成。

**为什么同一个模型在代码布局里表现不同？** 代码会话使用另一套配置：文件、shell 和 git 工具，
一套编码提示词，以及上下文计量器。参见
[工作区与会话](/docs/code-workspaces)。
