---
title: 键盘快捷键
description: Zylara 中所有全局、输入框、命令面板和列表快捷键。
---

`Ctrl` 用于 Windows 和 Linux，`⌘` 用于 macOS。仅在某个布局中存在的快捷键会标注出来。

## 全局

| 快捷键 | 操作 |
| --- | --- |
| `Ctrl/⌘ K` | 打开/关闭命令面板 |
| `Ctrl/⌘ B` | 打开/关闭侧边栏 |
| `Ctrl/⌘ N` | 新建对话 |
| `Ctrl/⌘ ,` | 打开设置 |
| `Ctrl/⌘ J` | 聚焦输入框（文本字段处于焦点时忽略） |
| `Esc` | 关闭浮层 → 离开技能或资料库 → 停止流式输出 |

`Esc` 是分层的：先关闭模型选择器、设置、产物与来源面板，然后从技能或资料库返回对话，最后才
停止正在进行的回答。

## 代码布局

| 快捷键 | 操作 |
| --- | --- |
| `Ctrl/⌘ Shift+A` | 新建代码会话 |
| `Ctrl/⌘ Shift+T` | 以中央标签页打开终端 |
| `Ctrl/⌘ L` | 聚焦输入框 |

计划模式和权限模式没有默认键位：请使用输入框中的 **计划** 胶囊与权限胶囊，或 `/plan` 与
`/permissions`。

## 输入框

| 快捷键 | 操作 |
| --- | --- |
| `Enter` | 发送（或 `Ctrl/⌘ Enter`，取决于 **发送方式**） |
| `Shift+Enter` | 换行 |
| `↑` / `↓` | 在 `/` 或 `@` 菜单中移动 |
| `Enter` / `Tab` | 接受高亮项 |
| `Esc` | 关闭菜单 |
| `Ctrl/⌘ Enter` | 编辑消息时保存并重新发送 |
| `Esc` | 取消消息编辑 |

## 命令面板

| 快捷键 | 操作 |
| --- | --- |
| `↑` / `↓` | 移动 |
| `Home` / `End` | 第一项或最后一项 |
| `PageUp` / `PageDown` | 按页移动 |
| `Ctrl+N` / `Ctrl+P` | 向下或向上移动 |
| `Enter` | 运行选中的命令 |
| `Ctrl/⌘ Enter` | 运行次要操作（置顶或取消置顶） |
| `Esc` | 先清空搜索，再关闭 |

输入 `>` 只搜索命令，输入 `#` 只搜索对话。

## 消息与列表

| 快捷键 | 操作 |
| --- | --- |
| `Alt+↑` / `Alt+↓` | 在可排序列表中调整条目顺序（对话、置顶智能体） |
| `Esc` | 拒绝待处理的批准 |
| `Ctrl+Alt+Shift+Q` | 在使用电脑操作时释放键盘 |

## 没有快捷键的鼠标与面板操作

| 操作 | 位置 |
| --- | --- |
| 切换布局 | 标题栏胶囊（**聊天**、**代码**、**智能体**） |
| 隐藏某个布局 | 右键点击该胶囊 |
| 让产物面板浮动或停靠 | 面板页眉 |
| 在标签页中打开文件 | 在文件树中点击该文件 |
| 与某个分支比较 | 更改筛选菜单 |
