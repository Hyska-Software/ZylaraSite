每个聊天都是一个存储在本地对话。标题由第一条消息生成，并随对话演进而更新；你可以随时重命名。

## 历史记录

侧边栏按时间远近对对话分组：**已置顶**、**今天**、**昨天**、**最近 7 天**、**最近 30 天**、**更早**。把经常重新打开的对话置顶 — 已置顶的对话不受日期分组影响，始终留在顶部。拖动行（或按 `Alt+↑` / `Alt+↓`）可在分组内调整顺序。

## 查找对话

- `Ctrl/⌘ K`，然后按 `#`，按标题和内容搜索对话。
- 侧边栏中的 **搜索对话** 行会打开同一个面板。
- 从面板中搜索也会匹配命令，因此你可以一次按键从聊天跳到 **打开产物面板** 或 **切换模型**。

## 重命名、导出、删除

打开对话行上的 `⋯` 菜单：

| 操作 | 结果 |
| --- | --- |
| **置顶 / 取消置顶** | 让对话保持在侧边栏顶部 |
| **重命名** | 设置自定义标题 |
| **导出** | 把对话以 Markdown 写入你选择的文件 |
| **在代码中使用 / 从代码中移除** | 把聊天关联到代码布局，或取消关联 |
| **删除** | 确认后移除该对话 |

删除对话会移除它的消息以及属于它的产物。你已保存到磁盘其他位置的文件不受影响。要一次性清除所有内容，请使用 **设置 → 数据 → 清除数据…** — 参见[数据与隐私](/docs/data-and-privacy)。

## 消息操作

| 位置 | 操作 |
| --- | --- |
| 助手消息 | **复制回答**、**重新生成回答**、**回答有帮助**、**没有帮助** |
| 你的消息 | **复制消息**、**编辑消息** → **保存并重新发送**（`Ctrl/⌘ Enter`）或取消（`Esc`） |
| 思考区块 | 展开一次工具调用以阅读 **输出** 和 **复制输出** |
| 产物卡片 | 打开预览、**另存为…**、**在默认应用中打开** |

编辑消息会截断它之后的所有内容，并再次发送编辑后的版本。聊天中没有分支；分支存在于代码布局中，会话可以回到更早的时间点。

## 消息排队

回答流式输出时，发送按钮会拆分：

- **立即发送**（⚡）中断当前回答，并立刻发送你的消息。
- **排队消息**（↑）把它存起来，在当前轮次结束后立即运行。

输入框上方的队列栏显示 **已排队 · N**，以及 **恢复队列**、**暂停队列**、**立即发送**、**清空队列** 和单条的 **从队列中移除**。队列按对话独立，并在重启后保留；每个对话同一时间只运行一个轮次。

## 会话与布局

对话的作用域限定在创建它的布局中：

- **聊天** 对话只出现在聊天侧边栏。
- **代码** 会话只出现在代码侧边栏，并绑定到一个工作区。
- **智能体** 线程属于它所属的智能体。

**在代码中使用** 会把已有的聊天对话关联到代码布局，让编码智能体可以用文件工具继续它；它在两个布局中都可用，并在代码侧边栏中标记为 **来自聊天**。**从代码中移除** 会取消关联，不删除任何内容。

## 对话中的模型切换

在聊天中模型属于对话，在代码中属于会话。切换模型会在对话记录中插入 **模型已切换为 …** 分隔线，这样你可以分辨哪个模型产生了哪个回答。由其他模型写成的回答会以中立形式重放到下一次请求，而不是作为提供商的原始状态。

## 存储与保留

对话存放在应用数据文件夹中的 `zylara.db` 里；附件和产物存放在它旁边的子文件夹中。不会上传任何内容。如果需要可移植的副本，请导出对话；或者在应用关闭时复制整个文件夹来备份全部内容 — 参见[数据与隐私](/docs/data-and-privacy#备份与恢复)。
