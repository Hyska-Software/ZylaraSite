---
title: 智能体
description: 创建拥有独立模型、指令、记忆、工作区和权限的角色，并跟踪它们的开销。
---

智能体是你配置一次、可以在多个对话中复用的角色：名称、职责、模型、指令、可选记忆、可选文件夹
和权限模式。智能体布局就是创建、对话和管理它们的地方。

## 布局

侧边栏围绕智能体组织：

| 区域 | 内容 |
| --- | --- |
| 页眉 | **搜索智能体或对话**、**活动**（进行中的轮次）、**任务看板**、**新建智能体** |
| **置顶** | 你固定在顶部的智能体 |
| **分组** | 按部门分组的智能体，各自带最近线程和 **查看全部 (N)** |
| **频道** | 多智能体对话，带 **新建频道** |
| 页脚 | **插件**、**团队**、**例行任务**、**设置** |

智能体主页显示头像、名称和职责，两个胶囊——**工作区 · *权限*** 和
***token* 个 token · *费用***——以及 **新建对话**、**打开主对话**、**编辑智能体** 和它的
**从这些开始** 建议，随后是 **最近对话**。

右侧面板有四个标签页：**屏幕**、**例行任务**、**浏览器** 和 **数据**。当智能体有工作区时，
文件/更改/终端面板会出现在同一个停靠区。

## 创建智能体

**新建智能体** 打开带六个标签页的编辑器：

| 标签页 | 字段 |
| --- | --- |
| **身份** | **名称**、**职责**（默认 *Assistant*）、**部门**（General、Research、Engineering、Quality、Content、Operations、Data、Support）、**描述** |
| **头像** | 吉祥物的身体、表情、颜色和形状，或 **上传图片**（PNG/JPEG/GIF/WebP，最大 10 MB） |
| **模型** | **提供商**、**模型**、**备用提供商**、**备用模型** 或 **无** |
| **行为** | **智能体指令**、**开场建议**（最多三条）、**工作文件夹** 或 **应用内部文件夹**、**权限**、**智能体 Docker 镜像**（可选）、**电脑环境** |
| **能力** | 十二个开关，以及 **工具**、**技能** 和 **MCP 服务器** 的白名单，和 **持久记忆** |
| **记忆** | 智能体已存下的记忆，可新增、置顶和删除 |

副标题说得很直白：*"指令不会给智能体授予权限。"* 提示词可以提出要求；只有权限模式和能力才
能真正允许。

团队页面里的 **模板** 提供八个现成角色：Assistant、Researcher、Engineer、Reviewer、Writer、
Operations、Analyst 和 Support。**用 AI 创建** 会依据一段描述起草智能体；草稿会在保存前
于编辑器中审阅。

## 能力

| 能力 | 启用的内容 |
| --- | --- |
| **搜索网页** | 带引用的网页搜索 |
| **文件访问** | 在工作区中读写，以及产物 |
| **运行代码** | 代码沙箱，前提是全局启用了代码执行 |
| **委派任务** | 委派、交接和在频道中发言 |
| **自动化** | 智能体自己的例行任务 |
| **共享记忆** | 写入对其他智能体可见的记忆 |
| **编写技能** | 创建并版本化 `SKILL.md` 文件 |
| **创建智能体** | 创建新的智能体 |
| **电脑操作** | 截图、点击和键盘输入，逐项批准 |
| **屏幕捕获** | 只读的屏幕访问 |
| **受控浏览器** | 通过 CDP 驱动的隔离浏览器 |
| **覆盖 Docker** | 每个智能体独立的 Docker 镜像 |

白名单会收窄智能体所见的内容：只有列出的工具、技能和 MCP 服务器才会提供给它。

## 记忆

启用 **持久记忆** 后，智能体会跨对话保存事实、偏好、流程和笔记。它通过 `memory` 工具写入
（列出、保存、更新、遗忘）。

| 限制项 | 数值 |
| --- | --- |
| 单条记忆大小 | 4 KiB |
| 每个智能体的记忆条数 | 200 |
| 上下文预算 | 8 KiB（5 KiB 私有 + 3 KiB 共享） |

记忆在每轮开始时作为易变区块注入，置顶的在前，然后是最新的。它永远不会进入冻结的系统提示词，
因此开启或关闭记忆不会让整个提示缓存失效。面板中的 **数据 → 记忆** 列出全部内容，带
**私有** 和 **共享** 标签页；全部删除需要确认。

关闭持久记忆会保留笔记，但把它们移出上下文。

## 工作区

智能体可以在一个文件夹里工作：

- **应用内部文件夹**——`<app-data>/agent-workspaces/` 下每个对话一个私有文件夹，与其他对话
  分开。文件工具在那里可用，但 shell、作业、计划和 MCP 工具不可用。
- **工作文件夹**——你选择的文件夹。经过 **信任这个文件夹吗？→ 信任并选择** 之后，所有工具
  都被限制在其中，完整的代码工具集也变为可用。

在一轮正在运行时更改文件夹会被拒绝，已有线程保持它们最初的工作区。对话也可以设置自己的
**文件夹** 胶囊。

## 团队与统计

**团队** 列出 *"你随时可以调用的智能体"*，并提供 **创建智能体**、**用 AI 创建**、
**模板**、**统计** 和 **导入**。每张卡片显示身份、描述、对话数量、最近活动、token 和费用，
并提供 **对话** 与 **归档**。已归档的智能体位于单独区块，带 **恢复** 和删除。

**统计** 覆盖 **7 天**、**30 天**、**90 天** 或 **全部**，卡片包括 **已用 token**（输入、
输出、思考）、**总支出**、**轮次数**（每轮平均 token）和 **最常用模型**，另有一张
**每日用量** 图表和一张 **按模型** 表格。费用是提供商上报的数值。

## 共享与生命周期

| 操作 | 结果 |
| --- | --- |
| **导出** | 写出一个包含配置和记忆的 `zylara-agent` JSON |
| **导入** | 从该文件重建智能体，并校验版本、模型和工作区 |
| **复制** | 复制配置，不复制对话和记忆 |
| **归档** | 保留历史、阻止新轮次；在归档区块中 **恢复** |
| **删除** | 仅当智能体没有其他对话时可用；删除已归档的智能体会移除角色、主对话以及它拥有的全部对话 |

**设置 → 智能体** 为每个智能体增加每日预算（美元）、并发轮次与每个线程排队消息的上限，以及
通知偏好（批准、提问、完成、任务、勿扰）。
