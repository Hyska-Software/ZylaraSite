title: 工作台
description: 文件、更改、差异、提交、分支、历史记录和终端，与智能体并排。
---

代码布局在对话记录旁边放了一张工作台。右侧面板有三个标签页——**文件**、**更改** 和
**终端**——文件、差异和提交历史则以中央标签页打开。

## 文件

目录树按 Git 状态给工作区加标记：**已修改**、**新增**、**已删除**、**已重命名**、**已复制**、
**有冲突**、**未跟踪** 和 **已忽略**。**筛选文件…** 可缩小目录树；计数器显示
*"显示 N / M 个文件"*。

点击文件会在中央标签页打开，带行号和语法高亮。Markdown 文件可切换 **文档 / 代码**，标签页
还提供 **自动换行**、**重新加载文件** 和 **在外部编辑器中打开**。图片和 PDF 内嵌预览。工作台
里的文件是只读的：修改要么通过智能体，要么通过你自己的编辑器。

## 更改

面板按状态给更改分组：

| 分组 | 含义 |
| --- | --- |
| **已暂存** | 已进入索引，可提交 |
| **未暂存** | 工作树中被修改 |
| **新增** | 未跟踪的文件 |
| **来自会话** | 本次会话中智能体碰过的文件 |

标记会注明来源：改动来自智能体操作日志时显示 **agent**，两者一致时显示 **agent + git**。
**全部暂存** 和 **全部取消暂存** 作用于整个分组；每个文件另有 **暂存** 和 **还原**。

筛选菜单切换比较基线：**上一轮**、**未提交**、**未暂存**、**已暂存**、**提交 <hash>**、
**分支 <name>** 以及 **与某个分支比较**。

合并冲突会显示横幅——*"存在合并冲突——解决后再提交"*——并在解决前禁用 **全部暂存**。

### 差异与还原

打开被修改的文件会显示统一或并排差异，支持折叠区块和 **复制补丁**。体积过大或二进制的文件
改以卡片呈现，而不是差异。

- **还原文件** 在确认后把该文件恢复到之前的内容。
- **还原本轮**（轮次页脚的 **还原**）撤销上一轮里的全部文件改动。
- 两者都不会删除对话。

还原基于操作日志：智能体通过自身工具做的改动可以撤销。被智能体运行的 shell 命令（格式化
工具、生成器）重写的文件只会体现为 Git 改动，需要通过 Git 还原，而不是通过操作日志。

## 提交

提交栏位于更改面板下方：

| 字段 | 选项 |
| --- | --- |
| 范围 | **全部**、**已暂存 (N)** 或 **选择 (N)** |
| 提交信息 | **提交信息…**，或 **建议** 由 AI 撰写信息 |
| 操作 | **提交**，禁用时会显示原因 |

没有打开工作区、文件夹不是仓库、没有任何改动、所选范围内没有暂存内容，或提交信息为空时，
提交按钮会被禁用。成功时显示 **已创建提交 (hash)**。

智能体永远不暂存、不提交、不推送。审阅由你来做。

## 分支与远程

面板栏里的分支选择器可以切换分支并新建分支（**切换分支**、**新建分支**、**创建并切换**，
按本地与远程分组）。Git 菜单把 **Fetch**、**Pull** 和 **Push** 作为显式操作提供。它们绝不会
被智能体触发。

## 历史记录

**提交** 以中央标签页打开提交历史，面板则显示可折叠的 **最近提交 (N)** 列表。选中某个提交
可以看到它的文件和差异；更改筛选器可以把工作树与该提交做比较。

## 终端

**终端** 标签页是属于你的 shell，不是智能体的：

- 它在工作区文件夹中启动，使用你系统的 shell。
- **新建终端**、**清空终端**、**结束进程**、**重启终端**。
- 状态显示 **运行中** 或 **已退出（代码 N）**。
- 最多四个终端，5,000 行回滚，使用应用主题和 **设置 → 终端** 里的字体。
- 关闭终端标签页会终止其进程树。

`Ctrl/⌘ Shift+T` 以中央标签页打开终端。智能体改用命令和后台作业；需要交互式进程时，它会问
你。

## 轮次摘要

在一个工作区里跑完一轮后，对话记录会显示耗时、token 数、被改动的文件，以及一个 `+42 −7`
计数器，附带 **查看更改** 和 **还原**。**查看更改** 打开该轮的差异，这是提交前审阅智能体做了
什么的最快方式。
