---
title: 电脑操作
description: 在 Docker 中给智能体一个私有桌面，在屏幕标签页里实时观看，并逐项批准它的操作。
---

电脑操作让智能体可以操作一个图形环境：截图、点击、输入、滚动并读取窗口内容。在 Zylara 中，
这个环境是运行在 Docker 容器里的一个 **私有桌面**，在 **屏幕** 标签页中实时显示。

## 前提条件

- 已安装并运行 Docker Desktop 或 Docker Engine。
- 已下载过一次电脑操作镜像（镜像很大，且不会自动拉取）。
- 一个具备 **电脑操作** 能力、且 **电脑环境** 不为 **关闭** 的智能体。

对真实桌面的本地控制仅在 Windows 上受支持。在 macOS 和 Linux 上，受支持的路径是私有桌面
容器；“云端桌面”目前尚不可用。

## 配置

打开 **设置 → 智能体 → 私有桌面（电脑操作）**：

| 控件 | 用途 |
| --- | --- |
| **电脑操作镜像** | 容器使用的镜像 |
| **下载镜像** | 在首次会话之前拉取 |
| **启动 Docker** | 启动守护进程，最多等待 120 秒 |
| **电脑操作容器** | 显示容器状态 |
| **每轮操作数** | 默认 20 |
| **每小时操作数** | 默认 120 |
| **清理容器** | 移除已停止的容器和遗留实例 |
| **诊断** | 检查 Docker、镜像和容器 |

缺少某个条件时，**屏幕** 标签页会显示帮助卡片，提供 **安装/打开 Docker Desktop…**、
**下载镜像**、**配置 Docker**，以及用于开发的 **本地构建**。

对每个智能体，**运行环境** 选择器设置环境：**自动**、**私有桌面（Docker）**、**这台电脑**、
**浏览器** 或 **关闭**。

## 智能体能做什么

| 操作 | 说明 |
| --- | --- |
| 截图、窗口列表、无障碍树 | 读取桌面状态 |
| 点击、双击、右键、移动、拖拽、滚动 | 指针控制 |
| 输入文本、按键、聚焦窗口 | 键盘控制 |
| 等待 | 让界面稳定下来 |
| 读取/写入剪贴板 | 显式操作 |
| 浏览器（CDP） | 通过受控浏览器能力驱动的隔离浏览器 |

每一步都是一次工具调用，所以思考区块会准确显示智能体做了什么、按什么顺序。

## 批准与限制

- 在 **自主** 之外，每个操作都会弹出批准卡片（**允许** / **拒绝**），且没有持久授权：你批准的
  是这一个操作，不是整个会话。
- **每轮操作数** 与 **每小时操作数** 限制循环；默认值分别是 20 和 120。
- 敏感窗口由内置列表拒绝，**设置 → 智能体** 还可为桌面应用和浏览器主机添加允许与拒绝列表。
- 审计记录会记录操作；输入的文本不会被保存。
- 网络访问遵循受控浏览器的主机策略。

## 接管

需要时，屏幕标签页是可直接交互的：

| 控件 | 效果 |
| --- | --- |
| **接管控制** | 你的键盘和鼠标操控桌面 |
| **交还给智能体** | 把控制权还回去 |
| `Ctrl+Alt+Shift+Q` | 立即释放键盘 |
| **停止**（顶部栏） | 停止当前轮次 |
| **全部停止**（活动） | 停止所有正在运行的轮次 |

## 局限性

- 私有桌面是一个容器：它有自己的文件系统，除非你把文件复制进去，否则访问不到你的文件。
- 截图是图像；文本提取依赖无障碍树，而很多 Linux 应用只部分暴露它。
- 镜像很大；首次下载可能较慢，容器按需启动。
- 电脑操作不能替代代码工具：做文件处理时，工作区更快也更可靠。
