title: 产物

---

产物是智能体生成的文件：Markdown 报告、HTML 页面、CSV 表格、代码文件、PDF、DOCX、电子表
格、演示文稿、图片、音频或视频文件，或者 ZIP 压缩包。产物保存在 Zylara 内部，无需离开应
用即可预览、保存或打开。

## 产物是如何创建的

| 工具 | 格式 |
| --- | --- |
| **创建文件**（`create_file`） | Markdown、TXT/日志、HTML、CSV/TSV、JSON、SVG 和源代码——直接写入文本 |
| **代码执行**（`run_code`） | 其余全部：PDF、DOCX、XLSX、PPTX、PNG/JPEG/WebP/GIF/TIFF、音频、视频、ZIP 及其他二进制文件 |

文本格式只需打开输入框中的工具开关即可。二进制格式需要启用
[代码执行](/docs/code-execution)，并具备 Python 或 Node 环境。

每个产物写到 `artifacts/<id>/<name>`，元数据存进数据库，因此重启后仍然存在，并会出现在资
料库中。

## 在对话中

产物以紧凑卡片的形式显示在创建它的消息下方，每行最多两张。当一条消息产生四张以上时，对话
只显示前几张，并给出 **查看全部 (N)** 按钮，点击后以列表模式打开面板。

每轮结束后卡片与面板都会重新对齐，即使丢了事件也不会留下过期的卡片。

## 产物面板

可以从卡片、**查看全部**，或在命令面板中用 **打开产物面板** 打开它。

| 控件 | 用途 |
| --- | --- |
| **查看列表** | 以卡片形式显示本对话的所有产物 |
| **上一个 / 下一个产物** | 在列表中前后移动，附带 `1 of 3 artifacts` 计数器 |
| **另存为…** | 通过系统原生对话框将副本写到磁盘任意位置 |
| **用默认应用打开** | 把文件交给系统应用处理 |
| **删除** | 确认后移除该产物 |
| **关闭** | 隐藏面板 |
| 浮动 / 停靠 | 面板可以浮在对话之上，也可以停靠在旁边；停靠需要窗口足够宽 |

## 按格式预览

| 格式 | 预览 |
| --- | --- |
| Markdown | 渲染后的文档，可切换 **文档 / 代码** |
| TXT / 日志 | 带行号，可配置自动换行 |
| HTML | 在沙箱 iframe 中渲染 |
| CSV / TSV | 表格，自动识别分隔符（`,` `;` tab `|`） |
| JSON | 可折叠树视图，外加高亮源码；JSON 无效时退回代码视图 |
| 代码（30+ 种语言） | 语法高亮，可自动换行或横向滚动 |
| SVG | 清理后渲染，支持缩放与适应窗口 |
| PDF | 翻页与缩放（pdf.js） |
| DOCX | 在沙箱 iframe 中渲染的 HTML |
| XLSX | 网格视图，每个工作表一个标签页 |
| PPTX | 幻灯片卡片，含标题、正文和演讲者备注 |
| 图片 | 缩放、平移和透明棋盘背景；TIFF 会转换为 PNG |
| 音频 / 视频 | 原生播放器，显示元数据（24 MiB 以内的文件内嵌播放） |
| ZIP | 条目列表（最多 400 条）及摘要 |
| 其他二进制 | 识别出的格式加 4 KB 十六进制转储 |
| 任何不支持的格式 | 一张带 **另存为…** 和 **打开** 的卡片 |

Office 预览是结构性的：会显示文字、表格和幻灯片顺序，但不会还原颜色、图片、合并单元格和
精确版式。扫描版 PDF 不做 OCR。

## 处理产物

- **另存为…** 是唯一会写到应用数据目录之外的操作；没有原生对话框就不会覆盖任何文件。
- **用默认应用打开** 适合内置预览渲染不了的格式，例如音频或视频封装格式。
- 文件会一直保留，直到你删除该产物、删除所在对话，或清空应用数据。
- 所有对话的产物都列在 [资料库](/docs/library) 中，可以在那里搜索、收藏和重命名。

## 智能体能对它们做什么

智能体可以通过两个工具搜索并读取 **你所有对话** 的产物库：`list_artifacts`（按名称、对话
标题和文本内容搜索）和 `read_artifact`（把内容带入上下文，支持 PDF/DOCX/XLSX/PPTX 的文本
提取、图片元数据、ZIP 列表和分页）。

产物库只暴露产物及其元数据——绝不包含其他对话的消息——并且内容会被当作不可信数据处理，而
不是当作指令。
