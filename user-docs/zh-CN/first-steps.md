---
title: 快速上手
description: 连接提供商、选择模型、发送第一条消息、附加文档并拿回一个文件。
---

本篇演练大约需要五分钟，结束时你会在资料库中得到一个生成的文件。这里假设 Zylara 已经安装 — 参见[安装](/docs/installation)。

## 1. 连接提供商

打开 **设置 → 提供商**（`Ctrl/⌘ ,`）。列表会先显示推荐的提供商。

- **OpenCode Go / OpenCode Zen** — 粘贴来自 [OpenCode Console](https://opencode.ai/console) 的密钥。已有的 OpenCode CLI 登录会被自动检测到。
- **OpenAI** — 使用 **使用 ChatGPT 继续**（无需 API 密钥，使用符合条件的套餐），或以 `sk-` 开头的 API 密钥。
- **Anthropic** — 以 `sk-ant-` 开头的密钥。官方 API 按使用量付费。
- **Gemini** — 以 `AIza` 开头的密钥。
- **其他提供商** — **查看更多提供商** 列出另外 21 个基于密钥的服务。

按 **继续**，如果提供商提供该选项，再按 **测试连接**。提供商旁边的徽章会说明凭据的来源：**已配置**、**环境变量**、**OpenCode CLI**、**ChatGPT 账户** 或 **缺失**。

密钥保存在应用的 `secrets.json` 中，永远不会进入界面。细节和回退方式：[模型与提供商](/docs/models-and-providers#连接提供商)。

## 2. 选择模型

点击输入框中的模型标签。**选择模型** 对话框可以让你：

- 按名称、系列、标识符或能力搜索；
- 按 **收藏**、**视觉**、**思考** 和 **免费** 筛选；
- 缩小到单个提供商；
- 查看上下文大小、最大输出、每百万 token 价格、协议、知识截止日期和发布日期。

选择一个模型并用 **使用此模型** 确认。首次运行时，支持 **思考** 的通用模型是合适的默认选择；如果打算附加图片，则需要 **视觉** 模型。

标签旁边的 ✦ 按钮设置思考模式：**关闭**、从 **最低** 到 **最高** 的强度档位，或介于 **快速（~4k）** 和 **最高（~32k）** 之间的 token 预算。并非每个模型都提供相同的控制项；不提供时，应用会说明。参见[模型与提供商](/docs/models-and-providers#思考模式)。

## 3. 发送第一条消息

在输入框中输入内容并按 `Enter`（如果你在 **设置 → 通用** 中更改了 **发送方式**，则按 `Ctrl/⌘ Enter`）。回答流式输出时，你可以：

- 阅读可折叠的思考区块，其中列出推理和每次工具调用；
- 按停止按钮（或 `Esc`）中断；
- 按 ⚡ **立即发送** 中断并发送新消息，或按队列按钮把消息排入队列 — 参见[对话](/docs/conversations#消息排队)。

## 4. 附加文档

使用输入框中的 **+** 按钮、粘贴文件，或从剪贴板导入。支持 PDF、DOCX、PPTX、XLSX/ODS/CSV、文本、代码、JSON、HTML 和图片。文本在后端提取并作为上下文发送；图片原生发送给视觉模型。

针对该文件提出具体问题（“总结第 3 节”、“哪些行增长最快”）。附件标签会显示预览和移除操作。限制和提取规则：[附件](/docs/attachments)。

## 5. 请求文件

确认输入框中已启用 **创建文件**（工具开关），然后请求具体内容：

> 创建一份 Markdown 报告，其中包含一个表格，列出所附 PDF 中最大的三个风险。

回答中包含产物卡片。打开它查看预览，然后使用 **另存为…** 把副本写入磁盘上的任意位置。文件也会列在[资料库](/docs/library)中。

如果文件是真正的二进制格式（PDF、DOCX、XLSX、PPTX、图片、音频、视频、ZIP），智能体需要启用[代码执行](/docs/code-execution)，并安装 Python 或 Node。

## 6. 可选：试用代码布局

将布局切换控件切到 **代码**，按 **打开文件夹…** 并选择一个项目。阅读信任对话框：**信任** 允许智能体在该文件夹中读取、编辑和运行命令；**只读打开** 只允许读取。先从 **审阅** 权限模式开始，请求一个小改动，并在提交前检查差异。

继续阅读[工作区与会话](/docs/code-workspaces)和[权限与批准](/docs/permissions-and-approvals)。

## 检查清单

| 完成 | 步骤 | 位置 |
| --- | --- | --- |
| ☐ | 已连接提供商 | **设置 → 提供商** |
| ☐ | 已选择模型 | 输入框标签 → **使用此模型** |
| ☐ | 已选择思考模式 | ✦ 按钮 |
| ☐ | 已收到第一个回答 | 输入框 |
| ☐ | 已分析文档 | 输入框中的 **+** |
| ☐ | 已创建并保存产物 | 产物卡片 → **另存为…** |
| ☐ | 已在代码中打开文件夹（可选） | 布局切换控件 → **代码** |

## 如果出现异常

| 现象 | 解决方法 |
| --- | --- |
| 横幅要求提供提供商 | 按 **打开提供商** 并添加密钥。 |
| “没有 *提供商* 的 API 密钥” | 连接该提供商，或选择你已配置的提供商中的模型。 |
| 流式输出时模型标签被禁用 | 等待当前回答或将其停止；模型在一个轮次中是固定的。 |
| 没有出现产物 | 检查 **创建文件** 是否开启，以及模型是否支持工具调用。 |
| 未生成二进制格式 | 启用 **代码执行** 并安装 Python 或 Node。 |

更多：[疑难解答](/docs/troubleshooting)。
