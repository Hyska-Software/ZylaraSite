title: 例行任务与队列
description: 在智能体工作时排队消息，并安排只在应用打开时运行的重复指令。
---

有两种机制能让智能体持续工作，而不需要你反复敲提示词：一个用于当前对话的消息队列，以及按时间
运行的例行任务。

## 消息队列

当一轮正在流式输出时，输入框可以暂存你的下一条消息，而不是打断它：

- **排队消息**（↑）把它加入队列；**立即发送**（⚡）打断当前回答并立刻发送。
- 队列栏显示 **排队中 · N**，并提供 **恢复队列**、**暂停队列**、**立即发送**、**清空队列**
  以及逐条的 **从队列中移除**。
- 队列是先进先出且持久化的：关闭应用不会丢失。
- 每个对话同一时间只运行一轮。**设置 → 智能体 → 执行与队列** 设置全局轮次上限、每个智能体的
  上限（默认 1）以及每个线程可排队的消息数量。

**活动** 对话框列出正在运行的轮次，并提供 **全部停止**；侧边栏显示队列数量和针对该智能体的
停止操作。

## 例行任务

例行任务是一条保存下来的指令，按时间或事件运行，并把结果发布到智能体的主对话中。

从智能体侧边栏页脚打开 **例行任务**。页面提供 **日**、**周** 和 **月** 视图、**今天**、智能体
筛选（**全部智能体**）、**全部例行任务** 和 **新建例行任务**。

### 创建例行任务

| 字段 | 选项 |
| --- | --- |
| **智能体** | 由哪个智能体执行 |
| **标题** | 日历中显示的名称 |
| **指令** | 提示词；最大 8 KiB |
| **触发方式** | **按计划** 或 **按事件** |
| **频率** | **按间隔** 或 **每天** |
| **间隔（分钟）** | 5 到 10,080 分钟（一周） |
| **时间** | 每日例行任务的时与分 |
| **星期** | 允许运行的日子 |
| **启用** | 打开或关闭该例行任务 |

每个智能体最多可以有 **50 个例行任务**。

### 运行记录

| 操作 | 结果 |
| --- | --- |
| **立即运行** | 立即开始一次运行，不必等排期 |
| **运行记录** | 打开 *"*标题* 的运行记录"*，列出最近 30 次运行及状态 |
| **暂停 / 启用** | 停止或恢复排期 |
| **编辑** | 修改指令或排期 |
| **删除** | 移除该例行任务；主对话会被保留 |

智能体面板中的 **例行任务** 标签页显示 **运行历史** 和最近的运行。

### 例行任务能做与不能做的事

- 例行任务 **只在应用打开时运行**：调度器每 30 秒触发一次，并跳过错过的运行而不是补跑。云端
  不会有任何东西运行。
- 结果会发布到智能体的 **主对话**，因此你可以像其他回答一样事后阅读。
- 无人值守的运行在批准环节 **失败关闭**：如果指令需要智能体没有的权限，运行会停止，而不是去
  等待一个不在场的人。
- 通知遵循 **设置 → 智能体 → 通知**，包括 **勿扰** 和各事件的开关。

## 在选择它们之间

| 需求 | 使用 |
| --- | --- |
| 在不丢失当前回答的情况下追加一条消息 | 队列 |
| 每天或每小时重复同一条指令 | 例行任务 |
| 必须持续到目标达成的工作 | [目标](/docs/goals-and-tasks#目标) |
| 并行的一次性工作 | 新建对话或 [子智能体](/docs/goals-and-tasks#子智能体) |
