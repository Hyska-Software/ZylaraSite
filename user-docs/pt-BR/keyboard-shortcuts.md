---
title: Atalhos de teclado
description: Todos os atalhos globais, do campo de mensagem, da paleta e das listas no Zylara.
---

`Ctrl` no Windows e no Linux, `⌘` no macOS. Atalhos que só existem em um layout estão marcados.

## Globais

| Atalho | Ação |
| --- | --- |
| `Ctrl/⌘ K` | Abre e fecha a paleta de comandos |
| `Ctrl/⌘ B` | Mostra ou esconde a barra lateral |
| `Ctrl/⌘ N` | Nova conversa |
| `Ctrl/⌘ ,` | Abre as configurações |
| `Ctrl/⌘ J` | Foca o campo de mensagem (ignorado enquanto um campo de texto está em foco) |
| `Esc` | Fecha sobreposições → sai de Habilidades ou Biblioteca → para o streaming |

`Esc` é hierárquico: fecha primeiro o seletor de modelo, as configurações e o painel de artefatos e
fontes, depois volta de Habilidades ou Biblioteca para a conversa, e só então interrompe uma
resposta em andamento.

## Layout Código

| Atalho | Ação |
| --- | --- |
| `Ctrl/⌘ Shift+A` | Nova sessão de Código |
| `Ctrl/⌘ Shift+T` | Abre o terminal como aba central |
| `Ctrl/⌘ L` | Foca o campo de mensagem |

O modo de planejamento e o modo de permissão não têm atalho padrão: use os chips **Planejar** e de
permissão no campo de mensagem, ou `/plan` e `/permissions`.

## Campo de mensagem

| Atalho | Ação |
| --- | --- |
| `Enter` | Envia (ou `Ctrl/⌘ Enter`, conforme **Enviar com**) |
| `Shift+Enter` | Nova linha |
| `↑` / `↓` | Navega no menu de `/` ou `@` |
| `Enter` / `Tab` | Aceita o item destacado |
| `Esc` | Fecha o menu |
| `Ctrl/⌘ Enter` | Salva e reenvia durante a edição de uma mensagem |
| `Esc` | Cancela a edição da mensagem |

## Paleta de comandos

| Atalho | Ação |
| --- | --- |
| `↑` / `↓` | Move |
| `Home` / `End` | Primeiro ou último item |
| `PageUp` / `PageDown` | Move por página |
| `Ctrl+N` / `Ctrl+P` | Move para baixo ou para cima |
| `Enter` | Executa o comando selecionado |
| `Ctrl/⌘ Enter` | Executa a ação secundária (fixar ou desafixar) |
| `Esc` | Limpa a busca e depois fecha |

Digite `>` para buscar só comandos, `#` para buscar só conversas.

## Mensagens e listas

| Atalho | Ação |
| --- | --- |
| `Alt+↑` / `Alt+↓` | Reordena um item em uma lista ordenável (conversas, agentes fixados) |
| `Esc` | Nega uma aprovação pendente |
| `Ctrl+Alt+Shift+Q` | Libera o teclado durante o uso do computador |

## Ações de mouse e de painel sem atalho

| Ação | Onde |
| --- | --- |
| Trocar de layout | Pílula na barra de título (**Chat**, **Código**, **Agentes**) |
| Esconder um layout | Botão direito na pílula |
| Flutuar ou acoplar o painel de artefatos | Cabeçalho do painel |
| Abrir um arquivo em uma aba | Clique nele na árvore de Arquivos |
| Comparar com um branch | Menu de filtro de Alterações |
